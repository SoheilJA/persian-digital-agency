# آلاوبیکس · Alawebix

قالب استاتیک فارسی و راست‌به‌چپ برای استودیوی طراحی وب و توسعه نرم‌افزار.

[نمایش زنده](https://soheilja.github.io/persian-digital-agency/) · [مخزن GitHub](https://github.com/soheilja/persian-digital-agency)

## ویژگی‌ها

- هفت صفحه مستقل، سئوپذیر و کاملاً واکنش‌گرا
- پشتیبانی از RTL، فونت وزیرمتن و اعداد فارسی
- شش پوسته رنگی با ذخیره انتخاب کاربر
- انیمیشن‌های بهینه با پشتیبانی از `prefers-reduced-motion`
- اجزای مشترک و محتوای متمرکز در فایل‌های JavaScript
- بدون نیاز به فرایند بیلد یا وابستگی برای اجرا

## اجرا

در پوشه پروژه، یک سرور استاتیک اجرا کنید:

```bash
python -m http.server 8000
```

سپس آدرس `http://localhost:8000` را باز کنید.

## صفحات اصلی

| صفحه | آدرس |
|---|---|
| خانه | `index.html` |
| خدمات | `services.html` |
| وبلاگ | `blog.html` |
| درباره ما | `about.html` |
| تماس با ما | `contact.html` |

صفحات خدمت و مقاله با پارامترهای `?s=` و `?p=` ساخته می‌شوند؛ برای نمونه:

```text
service.html?s=web-development
post.html?p=hand-coded-websites
```

## ساختار پروژه

```text
.
├── *.html              صفحه‌های مستقل سایت
└── src/
    ├── css/output.css   استایل نهایی
    └── js/              داده‌ها، کامپوننت‌ها و منطق صفحات
```

## نکات

- تصاویر فعلی نمونه هستند و باید پیش از انتشار با تصاویر واقعی جایگزین شوند.
- ارسال فرم‌ها شبیه‌سازی شده و برای اتصال به سرور باید بک‌اند اضافه شود.
